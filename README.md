# **My Learning Philosophy**

I don't want to learn by memorizing syntax.

I want to understand:

1. **What does this thing do?**
2. **Why does it exist?**
3. **Where would I use it in a real project?**
4. **What does it connect to?**
5. **What happens when I combine it with something else?**
6. **How can I build something with it?**
7. **How can I break it safely in a practice environment?**
8. **How can I fix it?**

### My rule:

> **Learn → Build → Break → Debug → Understand → Build again.**
